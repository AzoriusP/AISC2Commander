# 人族完整对局流程测试

这是一条可重复执行的端到端验收路线：真人玩家使用鼠标处理建筑落点、镜头和全图寻路，使用 AISC2Commander 处理经济托管、生产、附件、科技、编组、持续任务和接敌操作，最终击破电脑对手。

参考开局为当前 5.0.16 的 [HeroMarine TvZ 8 worker opening](https://lotv.spawningtool.com/build/203190/)。测试目标是验证项目功能，不要求逐秒复刻职业比赛；时间允许前后偏差 10–20 秒，建筑前置和实际 Observation 状态优先于表中时间。

## 固定测试环境

- 模式：单机。
- 地图：`(2)Bel'ShirVestigeLE (Void).SC2Map`，或任意标准双人天梯图。
- 玩家：人族。
- 电脑：虫族，中等（Medium），AI Build 选择 Macro。
- 语音：佩戴耳机，先用“开始录音”校验一次转写，再开启“开始监听”。
- 战术指令集：保持 `config/command_plans.json` 中的“经济托管”“人族生化运营”“人族坦克推进”。
- 建议胜利时间：12–18 分钟。若主要目标是稳定验证而不是难度，将电脑降为 Easy，不改变测试步骤。

## 语音交互约定

- 在“开始监听”模式中，下表所有句子都会在切句后自动发送。
- 在“开始录音”模式中，普通指令转写后还要点击“发送指令”；精确的计划名、别名和计划控制口令会自动发送。
- 说出普通指令后，玩家可以立即切换选择；程序绑定的是提交瞬间的单位 ID。
- 触发“人族坦克推进”后，在第一行完成前不要改变当前选择，因为计划会先把提交时选中的部队设为 1 队。
- “攻击最近敌人”要求视野中已有敌人。没有可见敌人时，用鼠标在小地图上移动或攻击移动到目标区域，这是预期边界，不算失败。

## 完整时间轴

### 0. 启动与连接

| 玩家操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- |
| 双击 GUI，点击“开启对局”，按固定环境选择地图、种族和电脑。 | 无 | SC2 自动进入 realtime 对局；GUI 在 60 秒内显示“已连接”。 |
| 游戏开始后，不操作鼠标选择，使用一次单次录音。 | `开启经济托管` | 口令精确命中指令集并自动发送；界面显示使用本地确定性规则，创建“保持55个农民”持续任务。 |
| 确认语音正常后点击“开始监听”。 | 无 | 状态显示正在监听；之后每句语音自动进入命令队列。 |

通过标准：SCV 开始连续生产；资源、人口或基地忙时显示等待，而不是立即失败。

### 1. 0:00–2:30：一兵营、双死神、二矿

| 时间/状态 | 鼠标操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- | --- |
| 约 0:30，11 人口 | 用一名 SCV 在主矿路口放第一个补给站。 | 无 | 不再卡 11 人口，经济托管继续补 SCV。 |
| 约 0:55，13 人口 | 用同一名或附近 SCV 放兵营；兵营右侧留出附件空间。 | 无 | 兵营正常建造。 |
| 约 1:00 | 保持主矿附近气矿在视野中。 | `让最近的农民在最近气矿建造精炼厂` | 创建建筑任务；显示 SCV 前往气矿、建造进度和完成状态。 |
| 兵营接近完成 | 选中主基地。 | `选中的基地升级为轨道指挥部` | 预检通过后升级轨道；若基地仍在生产 SCV，应明确提示当前不可用，待空闲后重试。 |
| 兵营完成 | 无需选中兵营。 | `所有兵营生产2个死神` | 创建 2 个死神的生产任务；资源不足时持续等待，完成数从 0/2 变为 2/2。 |
| 约 2:10，18 人口 | 用 SCV 在二矿位置建造第二个指挥中心。 | 无 | 二矿开建。 |
| 空闲人口低于 8 | 在路口或二矿补第二个补给站。 | 无 | 持续生产恢复。 |

玩家操作方式：死神造好后框选它们，用鼠标右键走到地图中部侦察，不要直接送进敌方主矿。发现敌军后再撤回。

### 2. 2:30–5:30：三基地与 2-1-1 科技骨架

| 时间/状态 | 鼠标操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- | --- |
| 约 2:50 | 在主矿建造工厂，右侧留出附件空间。 | 无 | 工厂开始建造。 |
| 主兵营空闲且右侧无阻挡 | 选中主兵营。 | `选中的兵营建造反应堆` | 兵营建造 Reactor；错误建筑或空间被挡时在动作前明确失败。 |
| 约 3:10，资源允许 | 在三矿建造第三个指挥中心。 | 无 | 三基地经济开始成型。 |
| 工厂完成 | 无需选中工厂。 | `所有工厂生产4个恶火` | 正常生产 4 个恶火；队列或资源不足时显示等待。 |
| 约 3:50 | 建造第二个兵营；完成后选中它。 | `选中的兵营建造科技实验室` | 第二兵营获得 Tech Lab。 |
| 科技实验室完成 | 保持该兵营被选中。 | `选中的兵营研究兴奋剂` | 通过 `add_on_tag` 找到相连科技实验室，显示真实研究进度。 |
| 约 4:45 | 建造星港，右侧留附件空间。 | 无 | 星港开始建造。 |
| 星港完成 | 选中星港。 | `选中的星港建造反应堆` | 星港获得 Reactor。 |
| 星港和反应堆完成 | 无需保持选择。 | `所有星港生产4个医疗机` | 医疗运输机持续生产至 4/4。 |
| 工厂空闲 | 选中工厂。 | `选中的工厂建造科技实验室` | 工厂获得 Tech Lab，为坦克生产做准备。 |

人工补给规则：只要空闲人口不高于 8，就立刻用鼠标补 1–2 个补给站。指令集不会猜建筑落点，因此补给建筑由玩家负责。

### 3. 5:30–7:30：升级与自动暴兵

| 状态 | 鼠标操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- | --- |
| 兴奋剂完成 | 选中带科技实验室的兵营。 | `选中的兵营研究战斗盾牌` | 战斗盾牌开始研发并显示进度。 |
| 资源允许 | 建造两个工程站。 | 无 | 两个工程站均完成。 |
| 工程站 1 空闲 | 只选中工程站 1。 | `选中的工程站研究步兵武器` | 研究当前可用的步兵武器等级。 |
| 工程站 2 空闲 | 只选中工程站 2。 | `选中的工程站研究步兵护甲` | 研究当前可用的步兵护甲等级。 |
| 至少已有 2 兵营、1 星港、1 带科技实验室的工厂 | 不要求选择建筑。 | `启动人族生化运营` | 取消旧持续任务并创建：55 SCV、32 枪兵、8 劫掠者、4 医疗机、4 坦克。 |
| “人族生化运营”执行完毕后 | 无。 | `每90秒所有轨道指挥部向最近矿投放矿骡` | 创建周期持续任务；有足够能量的轨道向最近可见矿区投放矿骡。 |
| 持续任务运行约 15 秒后 | 无。 | `显示任务` | 列出经济、枪兵、劫掠者、医疗机、坦克和矿骡任务的状态。 |

这时用鼠标再增加 3 个兵营，并继续补给站。三座基地全部完成后，逐个选中并说 `选中的基地升级为轨道指挥部`。

通过标准：生产任务不会因一次资源不足消失；不同兵种可以并行推进；同一生产资源冲突时明确显示阻塞或等待。

### 4. 7:30–9:00：任务控制、编组与第一次防守

| 玩家操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- |
| 等待生产线正在工作。 | `暂停任务` | 所有非终止持续任务进入暂停；已经在生产队列中的单位允许完成，但不应继续派发新订单。 |
| 等待 5–10 秒。 | `继续任务` | 持续任务恢复，根据最新单位数继续补兵。 |
| 框选主力枪兵、劫掠者、医疗机和坦克，并保持选择到命令提交。 | `选中的单位设为1队` | 官方控制编组 1 被设置，界面回报操作成功。 |
| 只框选两个死神和四辆恶火。 | `选中的单位设为2队` | 侦察部队成为 2 队。 |
| 用鼠标将 2 队移动到地图中部，直到看到敌军。 | `2队攻击最近敌人` | 2 队攻击 Observation 中最近的可见敌军。 |
| 敌方第一次进攻进入视野时召回主力。 | `1队攻击最近敌人` | 主力攻击最近敌军。 |
| 敌军进入坦克射程前。 | `所有坦克攻城模式` | 当前所有可用坦克切入攻城模式。 |
| 双方正式交火。 | `所有枪兵使用兴奋剂` | 已完成兴奋剂且形态正确的枪兵使用 Stim。 |

通过标准：2 队命令不应错误操作 1 队；raw action 后 SC2 应恢复玩家原选择，不长期抢走鼠标上下文。

### 5. 9:00–11:30：补充产能与总攻准备

- 用鼠标补到 5–8 个兵营、1 个坦克工厂、1 个双倍医疗机星港。
- 维持三矿采集，空闲人口始终高于 8。
- 第一轮攻防后让坦克移动时，说 `所有坦克解除攻城`。
- 工程站空闲且资源足够时，继续分别说：
  - `选中的工程站研究步兵武器`
  - `选中的工程站研究步兵护甲`
- 再说一次 `显示任务`，确认枪兵、劫掠者、医疗机和坦克数量仍在向目标靠近。
- 当主力至少包含 16 枪兵、4 劫掠者、2 医疗机、2 坦克，且总人口约 100 以上时开始总攻。

如果电脑使用潜伏、隐形或埋地单位，保持敌人位置仍在视野附近并说：

`所有轨道指挥部扫描最近敌人`

预期结果：有足够能量的轨道对最近敌军位置执行扫描；没有能量时应明确拒绝，而不是伪造成功。

### 6. 11:30–结束：坦克推进与清场

| 玩家操作 | 玩家说的话 | 预期结果 |
| --- | --- | --- |
| 框选完整主力并用鼠标攻击移动到敌方二矿外围；等敌军进入视野。 | `坦克推进` | 精确命中“人族坦克推进”计划并自动发送；提交时部队设为 1 队，随后攻击、架坦克、枪兵兴奋剂和生化部队压进。 |
| 第一片阵地清空。 | `所有坦克解除攻城` | 坦克恢复移动形态。 |
| 用鼠标让 1 队攻击移动到敌方主矿或下一处分矿，直到再次看见敌人。 | `1队攻击最近敌人` | 主力攻击当前最近目标。 |
| 敌人形成第二道防线。 | `所有坦克攻城模式` | 坦克重新架起。 |
| 枪兵没有兴奋剂效果且生命允许。 | `所有枪兵使用兴奋剂` | 再次使用兴奋剂。 |
| 敌方主矿被摧毁后。 | `所有坦克解除攻城` | 主力可以继续清理剩余建筑。 |

最后的全图寻敌由玩家看小地图，用鼠标控制 1 队依次攻击仍显示为敌方颜色的区域。项目的“攻击最近敌人”只使用当前 Observation 中可见的目标，不负责猜测战争迷雾后的建筑位置。

## 胜利与收尾标准

满足以下全部条件，完整流程测试通过：

1. SC2 显示胜利，官方 Observation 返回 `player_result`。
2. GUI 消息区出现“游戏已经结束，项目正在停止”。
3. 开局的精炼厂、附件、轨道升级、科技研究均经过官方能力和资源预检。
4. 至少一个生产任务经历过“等待资源/人口/生产位”并最终完成。
5. “人族生化运营”成功创建多个持续任务，暂停和继续有效。
6. 1 队、2 队分别执行过命令，没有串组。
7. 至少成功执行一次攻城模式、解除攻城、兴奋剂和扫描或矿骡。
8. “人族坦克推进”从开始到结束没有因缺少单位、科技或可见敌人而中止。
9. 日志中没有无法对应到具体任务的 Blizzard Action Error。

对局结束后，不要直接关 GUI。先等待项目自动停止；若 8 秒后仍未退出，再点击“强制停止”，并保留 `logs/aisc2commander.log` 作为测试证据。

## 常见失败与判定

| 现象 | 是否为缺陷 | 处理方式 |
| --- | --- | --- |
| “攻击最近敌人”提示没有可见目标 | 否 | 用鼠标侦察或移动到接敌位置后重试。 |
| 空闲人口为 0，生产任务等待 | 否 | 手动补给站；任务随后应自动继续。 |
| 附件无法建造 | 通常不是 | 检查生产建筑右侧是否被其他建筑或地形阻挡。 |
| 研发兴奋剂失败 | 通常不是 | 确认选中的是带科技实验室的兵营，并且建筑空闲、资源足够。 |
| “坦克推进”在第一行后停止 | 条件性 | 检查触发时是否框选主力、视野中是否有敌人、是否已有坦克和兴奋剂。 |
| 持续任务一次资源不足后永久消失 | 是 | 记录任务编号、时间和日志，应作为重试/状态机缺陷提交。 |
| 对局已经胜利但项目不自动停止 | 是 | 保存日志，8 秒后使用“强制停止”。 |
